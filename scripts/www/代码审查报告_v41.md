## 2. P0：必修（安全 / 资源 / 数据丢失）

### 2.1 ★★ 原型链污染（两个 `deepMerge`）

**位置**：`sunview.js:194-203`、`app.js:288-296`

```js
// sunview.js:194
function deepMerge(dst, src) {
  if (!src || typeof src !== 'object') return dst;
  Object.keys(src).forEach(function (k) {
    var sv = src[k];
    if (sv && typeof sv === 'object' && !Array.isArray(sv) &&
        dst[k] && typeof dst[k] === 'object' && !Array.isArray(dst[k])) deepMerge(dst[k], sv);
    else if (sv !== undefined) dst[k] = sv;
  });
  return dst;
}
```

`k` 未过滤。`JSON.parse('{"__proto__":{"x":1}}')` 会建立一个**自有属性** `__proto__`；`dst['__proto__']` 于是取到 `Object.prototype`（对象类型）→ 递归进入 `deepMerge(Object.prototype, sv)` → 攻击者键值写入 `Object.prototype`，影响整页所有对象。存档来自 `localStorage`，属同源但可被共享链接/污染书签触发。

**修法**：

```js
var DANGER = { __proto__: 1, constructor: 1, prototype: 1 };
function deepMerge(dst, src) {
  if (!src || typeof src !== 'object') return dst;
  Object.keys(src).forEach(function (k) {
    if (DANGER[k]) return;                       // ★ 关键一行
    var sv = src[k];
    if (sv && typeof sv === 'object' && !Array.isArray(sv) &&
        dst[k] && typeof dst[k] === 'object' && !Array.isArray(dst[k])) deepMerge(dst[k], sv);
    else if (sv !== undefined) dst[k] = sv;
  });
  return dst;
}
```

更彻底的做法是在解析阶段就丢弃：

```js
JSON.parse(s, function (k, v) { return k === '__proto__' ? undefined : v; });
```

### 2.3 ★★ 综合视图重入泄漏 WebGL 上下文 + 事件监听

**位置**：`sunview.js:2205`、`2252`、`2265`

- `2205` `wrap.innerHTML = ''` 直接丢弃旧窗格的 `o._r`（`WebGLRenderer`，创建于 `2419`），从不 `dispose()` / `forceContextLoss()`。浏览器 WebGL 上下文上限约 16，加上基线 4 个（`800`、`1741-1743`）→ **进出综合视图几次即导致主画布黑屏**。

**修法**：

```js
// leaveSunCombo / 重建前
Object.keys(sComboCells).forEach(function (k) {
  var c = sComboCells[k];
  if (c._r) { c._r.dispose(); if (c._r.forceContextLoss) c._r.forceContextLoss(); }
  if (c._off) c._off();                    // makeSunComboCellDrag 返回解绑函数
});
```

或把监听改挂在 `cell` 上（节点移除时监听随节点回收）。

### 2.5 ★ `app.js` 侧几何泄漏

**位置**：`app.js:9404-9419`（`syncPoints`）、`9704-9718`（`syncFigure`）

`syncPoints` 只释放了 sprite 的 `material.map` 与 `material`，**没有释放 `new THREE.SphereGeometry(0.020,14,10)`**；随后 `while (ptsGroup.children.length) ptsGroup.remove(...)` 摘掉网格但几何仍被 GPU 持有。每个点 × 2 个场景 × 每次重建 = 漏一个几何。

**修法**：统一写一个树干式释放，**并白名单排除共享几何**（`hourDotGeo`、`bandGeo`、`clickMarker` 用的几何），否则会连带销毁仍在使用的对象。

```js
function disposeTree(obj) {
  obj.traverse(function (o) {
    if (o.geometry && SHARED_GEOMS.indexOf(o.geometry) < 0) o.geometry.dispose();
    /* material / uniforms 贴图同理 */
  });
}
```

**补充**：全仓无 `webglcontextlost` 监听 → 集显驱动重置后画面永久黑屏，只能刷新。建议补：

```js
canvas.addEventListener('webglcontextlost', function (e) { e.preventDefault(); }, false);
canvas.addEventListener('webglcontextrestored', function () { rebuildAllGpuResources(); resize(); }, false);
```

### 2.6 ★ `restore()` 标量不校验 → NaN 路径

**位置**：`sunview.js:1057`、`1362`、`4733`、`1321`

`restore()` 对**对象**做了详尽归一化（`261-307`），但**标量一律不校验**。而 `clamp(v,a,b)`（`29`）对 `NaN` 返回 `NaN`（两侧比较均为假）：

| 位置 | 后果 |
|---|---|
| `1057` `var N = clamp(Math.round(S.traj.n), 24, 240)` | `NaN` → `1060` 循环不执行 → `1066` `new THREE.CatmullRomCurve3([])` **抛异常** |
| `1362` `if (horizonRing.userData.w === w) return;` | `w` 为 `NaN` 时 `NaN === NaN` 为假 → **每帧** dispose 并重建 `TorusGeometry`（帧率崩塌） |
| `4733` `ensureBeams(clamp(Math.round(S.vol.n), 1, 15))` | 同上 |
| `1321` `var d = clamp(S.spacing, 4, 26)` | 同上 |

**修法**：① `restore()` 末尾加标量「键名 + 值域」白名单归一；② `clamp` 加兜底：

```js
function clamp(v, a, b) { if (!isFinite(v)) return a; return v < a ? a : (v > b ? b : v); }
```

## 8. 安全 / 隐私小结

**干净的部分**（明确核实）：

- 全仓**无 `eval`、无 `new Function`、无 `document.write`**；
- 无远程请求（`fetch`/`XMLHttpRequest` 均 0 命中）；图标为内联 SVG Data URI；
- `localStorage` 读取全部包在 `try/catch`（`app.js:286-287`、`sunview.js:192-193`）；
- `app.js` 的 43 处 `innerHTML` 绝大多数为静态模板/常量；**未发现**把用户输入（标记文本、点名称）拼进 `innerHTML` 的路径 —— 列表项走 `createElement` + `className`（`9460-9463`、`9890-9892`、`10300-10305`）。

**需修的部分**：

1. **原型链污染**（§2.1）—— 唯一真实安全问题；
2. **`esc()` 不转义引号 + `sunview.js:3938-3945` 的存档来源插值**（§2.7）；
3. **形状校验是手写的**（`app.js:872-1008`、`sunview.js:240-321`），`app.js:978-980` 的注释自认「老存档残留非对象字段 → NaN 几何」——新增字段漏归一化即重演 → 建议改 schema 驱动的一次性校验；
4. **`Object.assign(state, JSON.parse(JSON.stringify(DEFAULTS)))`**（`app.js:8123`/`8252`）整体替换对象引用 → 任何缓存了 `state` 子对象引用的地方都会失联（`window.__pmSize` 即实例）；
5. 隐私：`sunview.js:329` `save()` 把观测点经纬度与用户摆放物体整份写入 `localStorage`（同源、无上传）—— 可接受，但无告知/清理入口（仅「重置所有设置」会 `removeItem`）。

## 10. 可扩展功能建议

### A. 交付形态（性价比最高）

1. **PWA 离线化** —— 全包已零外部依赖，只差 `manifest.webmanifest` + Service Worker 预缓存（`index.html` + 7 个 js/css + `assets/coast-vectors.js` + `vendor/three.min.js`）。教室无网、平板离线是真实场景。**首推。**
2. **单文件 HTML 导出** —— 资源已是 Data URI，只需内联 CSS/JS，双击即用、便于发给学生。
3. **状态分享链接** —— hash 参数已存在（`#view=`/`#date=`/`#mode=`/`#mon=`/`panel=all`，`app.js:11390-11421`），加「复制当前状态链接」按钮 + 文档化参数表。

### B. 教学刚需（导出与留痕）

4. **截图 / 录屏导出** —— 从 `renderer.domElement` 取帧导出 PNG（可叠加时间戳与读数）；或用 `captureStream` + `MediaRecorder` 录「自转一圈 / 一年直射点回归」。项目已有 `tools/_vidframes.js` 骨架可复用。
5. **数据表 CSV 导出** —— 当前时刻的全球/指定纬度表（直射点经纬度、昼长、正午太阳高度、日出日落地方时、太阳方位）。计算函数（`yearDayLens`、`renderGeoInfo` 的公式）都已存在，只缺出口。
6. **课堂自测卡** —— 给定日期与纬度提问「昼长/正午太阳高度/直射点在哪个半球」，学生先作答再看 3D 验证。

### C. 教学深度（复用现有基建）

7. **地形起伏（凹凸贴图）** —— 从 `assets/geo-land.png` 的 G 通道生成 bump/normal map，着色器加 `uBump`。成本极低，「3D」感提升明显（青藏高原、安第斯在侧视时可见）。
8. **日影 / 日晷演示** —— 复用 `updateFigureShadows`（`app.js:9816`）在观测点画立杆，画出**一天内影端轨迹**（影端曲线 + 正午最短影长）。
9. **全年昼长多纬度对照曲线** —— 扩展 `drawYearCurve`（`app.js:10848`）叠加多个纬度，一条图讲清「纬度越高年较差越大」。
10. **恒星日 vs 太阳日对比** —— 同一颗恒星连续两次过中天 vs 太阳，课标里常被讲糊涂的点。
11. **天球三套坐标系切换**（地平 / 赤道 / 黄道）—— 让学生看清「地平坐标随纬度变化」。
12. **星空周日运动 / 星迹长曝光** —— 天球视图已有恒星层基础，可加北极星附近的同心圆弧。

### D. 工程与体验

13. **`tuneResolution` 降档提示** —— 当前静默从 DPR 1.0 降到 0.58（`app.js:9132-9147`），用户只觉「画面糊了」。加提示或菜单项化（「性能模式：自动 / 高画质 / 流畅」）。
14. **统一 `FMTS`/`MAPS` 为单一来源** —— 消除 `pct` 同名不同义这一类系统性风险。
15. **渲染侧门控自动派生** —— 把 `spriteNoteGate` 的手写 `if` 链改为由菜单 `gate:` 串驱动，两处维护变一处。
