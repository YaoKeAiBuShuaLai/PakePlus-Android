### ★ v43（需求一·7）面板标题条左右铺满 —— `--pad-x` 出血机制
- **规则**：`.card > .card-head { margin: 0 calc(-1 * var(--pad-x, 0px)) 0; }`（`style.css`）。**每个带 `.card-head` 的卡片都必须声明 `--pad-x`**（值 = 该卡片自身的水平 `padding`），否则负 margin 抵消量为 0，表头会浮在卡片里、左右各留一条与 padding 等宽的空隙（实测 10–17px）。
- **基准口径**：卡片有 `border: 1px`，所以表头左右边缘与卡片**外**边缘的差值应为 **1px**（不是 0）。主模块 `#timeCard` 实测 `dL = dR = 1`。
- **配套隐患**：`sunview.css` 的 `.card .card-body { padding: 0 var(--pad-x, 0px); }` 会与卡片自身 padding **叠加**成双倍内缩，含 `.card-body` 的面板必须显式归零（`#svOptsCard .card-body { padding: 0; }`）。
- **已声明 `--pad-x` 的容器**：`#svOptsCard` 16px、`#svTimeTop` 16px、`#svTimeBar` 16px、`#svMonitor` 14px、`.svwin` 10px、`.mvwin` 10px、`#svModalHost .svm-card` `calc(16px * var(--ui))`。探针 `tools/_probe_v43_head.js` 20 项断言。
